# C port equivalence (S3)

Written by `python/compare_c.py` (`make equiv`). The C filter (`c/tools/ekf_run_csv`) runs experiment 1 (soc0 = the reference SoC at row 0) on the 63 runs of the evaluation set and the tuning cycle, with the frozen noise settings of `results/s2/ekf_config.json` (q_soc = 1e-07, q_v = 1e-06, r = 0.01), on the filter inputs as the loader gives them (dt computed in float64 by Python, written with 17 significant digits). delta SoC = Python SoC - C SoC over every row of a run, in pp; the Python SoC is the experiment 1 trace of `python/run_all.py`. The float build uses `ekf_real_t = float`, the double build `-DEKF_USE_DOUBLE`; the thresholds on max |delta SoC| are those of the spec. The tool writes SoC with 10 significant digits, so the double build's numbers sit at that resolution: half a unit in the 10th digit of a SoC between 0.1 and 1 is 5e-9 pp.
