# Data checks (S0)

Generated by `python/data_checks.py` (`make checks`) from `data/raw/`: LG 18650HG2 Li-ion Battery Data, Kollmeyer et al., McMaster University, Mendeley Data v2, DOI 10.17632/b5mj79w5w9.2, CC BY 4.0. Do not edit by hand. Every number is measured from the `.mat` files.

These are the measured dataset properties that `docs/decisions.md` and `docs/model.md` cite and that `results/data_inventory.md` and `results/capacity.md` do not contain. Each section names the files it reads.

## Legend and conventions

- **Sign convention:** values quoted from the files (Current, Ah, V) are **as the cycler wrote them: discharge current is negative and the Ah counter falls while discharging**. Amounts named *removed*, *returned* or *charged* are positive. SoC_ref and the coulomb counter use the project sign, I = -Current (positive = discharge). Units: V, A, s, Ah, degC; SoC differences in percentage points (pp).
- **Rows** count from 0 in the file as stored, before any row is dropped. **Time** is the Time field (s); TimeStamp is used only where a section says so.
- **Q_ref** = 2.78074 Ah, measured by this script in section 12 and used everywhere below.
- **Rows used** (the loader rules of `docs/decisions.md` 1.9 and `docs/model.md`, applied in this order): (1) drop rows with Voltage <= 0 and rows with NaN in Time, Voltage, Current, Ah or Battery_Temp_degC; (2) per-file cuts: `10degC/571_Mixed6` starts at row 391, and `10degC/582_LA92` keeps only rows dated 26/11/2018 (section 4); (3) of consecutive kept rows that share one Time value, keep the last. Steps 1 and 2 commute: the dropped rows all lie outside the rows the cuts keep.
- **Evaluation set** (`docs/decisions.md`): 62 of the 70 drive files (25degC 10, 40degC 7, 10degC 11, 0degC 11, n10degC 11, n20degC 12). Not in it: `25degC/551_HWFET_25degC_LGHG2` (excluded: no current); `25degC/551_Mixed1_25degC_LGHG2` (tuning cycle); `40degC/562_Mixed4_40degC_LGHG2` (excluded: partial run); `40degC/562_Mixed5_40degC_LGHG2` (excluded: partial run); `40degC/562_Mixed6_40degC_LGHG2` (excluded: partial run); `40degC/562_Mixed7_40degC_LGHG2` (excluded: partial run); `40degC/562_Mixed8_40degC_LGHG2` (excluded: partial run); `n10degC/602_Mixed4_n10degC_LGHG2` (excluded: corrupt (frozen rows and a 416 s hole)). The six PausCycl files are not drive cycles and are not in it either.
- **Drive files** are the UDDS, HWFET, LA92, US06 and Mixed1 to Mixed8 files; files are named `<folder>/<test number>_<descriptor>` (the full names are in `results/data_inventory.md`).
- Sections 1 to 15 are the checks the S0 decisions rely on; 16 to 19 are further measured facts the docs cite.
