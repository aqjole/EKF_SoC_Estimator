# Model parameters

Written by `python/export_params.py` from `results/params.csv` (the tables on the 101-point SoC grid, which the C file is generated from) and `results/fit_levels.csv` (the HPPC level fits before resampling). Do not edit by hand.

Units: SoC in %, R in mOhm, tau in s, C = tau / R in F, RMSE in mV. `n/a` is a missing value: a failed fit, or R2 and tau2 of the last level, which has no 1 h rest.

## OCV

OCV comes from the C/20 discharge half, corrected onto the HPPC rest voltages (docs/decisions.md 1.1). Below the lowest SoC a discharge reached, the table holds its last value, so the OCV is measured from the first grid SoC where it changes from the node before it (from 0 when nothing is held).

OCV fallback (the 25 degC curve used at every temperature): no.

| T (degC) | OCV valid from SoC (%) | grid points held below |
|---|---|---|
| 40 | 4.0 | 4 |
| 25 | 0.0 | 0 |
| 10 | 5.0 | 5 |
| 0 | 7.0 | 7 |
| -10 | 8.0 | 8 |
| -20 | 11.0 | 11 |

## HPPC level fits

Per level, R0, R1 and tau1 come from the four discharge pulses and their 40 s rests, and are tabulated at the SoC of the level's pulses. R2 and tau2 come from the 1 h rest after the move at that level, and are tabulated at the SoC where the move ended (docs/decisions.md 1.12). `pulses used` is the number of discharge pulses left in the fast fit.
