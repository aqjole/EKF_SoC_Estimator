## Legend for the file tables

- Rows are sorted by the first TimeStamp of each file (not by the name, which is wrong for some files; see *flags*).
- *start (name)*: date and time from the file name, read as `MM-DD-YY_hh.mm` as the readme says. *flags* says when this disagrees with the first TimeStamp by more than 5 min.
- *TimeStamp format*: month first with whole seconds in 25degC (`10/28/2018 5:44:00 PM`, midnight written as the date alone); day first with milliseconds in every other folder (`02/11/2018  6:30:13.000 PM`). The whole second sometimes lags the milliseconds by up to 1 s, so Time, not TimeStamp, is the sample clock.
- *type*: test type from the descriptor (`ekfsoc.rawio.classify_test`). *desc T*: temperature written in the descriptor (degC), `none` if absent.
- *duration*: (max Time - min Time) / 3600. *n*: number of rows. *median dt*, *max gap*: median and largest step of Time (s); in brackets, the number of steps longer than 1 s. *dup*: number of steps where Time does not advance (duplicate rows).
- *fields*: `8 expected` means exactly Time, TimeStamp, Voltage, Current, Ah, Wh, Power, Battery_Temp_degC. No file has a chamber temperature field.
- *V*, *I*, *T*: min / max of Voltage (V), Current (A, cycler sign) and Battery_Temp_degC (degC), NaN ignored.
- *Ah end*: last Ah value in the file (cycler sign). *integral I dt*: trapezoid integral of Current over Time in Ah (steps with dt <= 0 or NaN skipped); for a file whose counter starts at 0 it should match *Ah end*, which confirms units (A, s) and that Ah has the same sign as current.
- *regen*: drive cycles and PausCycl only; samples with current above +50 mA (charging) and the largest charging current.
- *full charge at start*: `yes` when the first sample is above 4.15 V with |I| < 50 mA, i.e. the cell sits at its full-charge rest voltage when the file starts (`yes: first sample ...`). A file that opens with current already flowing also counts as `yes` when the last sample logged before it in the same folder is such a rest, at most 300 s earlier, in a file that reached 4.19 V (CV phase) before it (`yes: rest at ...`); this covers e.g. the C/20, 0.5C and 2C tests and the Mixed4 and Mixed8 runs, which start straight after their Charge file. `no` means the file opens at rest at or below 4.15 V. `unclear` means the file opens under load and no such rest is logged before it; the cell gives the first sample and the last earlier sample in the folder. Rows with Voltage <= 0 are not used as evidence.
- Drive cycles whose full-charge start is not confirmed: `40degC/562_Mixed4_40degC_LGHG2` (opens under load at 4.163 V, -1.326 A; last earlier sample: 3.393 V at 0.000 A, 39285 s before (557_Charge10)); `0degC/590_Mixed4_0degC_LGHG2` (opens under load at 4.149 V, -1.320 A; last earlier sample: 4.188 V at 0.000 A, 15860 s before (589_Charge8)).
- *Voltage <= 0* (flag): rows where the cycler logged 0 V, an end-of-test sentinel that the S1 loader drops. Found in: `25degC/552_Charge16` (last row only), `40degC/557_Charge10` (last row only), `0degC/590_Charge16` (last row only).
- *overlap* (flag): the file's [first, last TimeStamp] span starts more than 2 s before the previous file of the folder ends and ends after it, so both files claim the same wall-clock minutes and any rest time computed across the pair is wrong by that much. Only neighbouring files are compared (each file with the file logged just before it). Found: `40degC/556_Charge1` starts 58.6 min before `555_Dis_2C_40degC_LGHG2` ends. A file whose span lies wholly inside the span of an earlier file of the folder is not an overlap and is not flagged; this is checked against every earlier file, not only the neighbour (`25degC/549_HPPC_25degC_LGHG2` inside `549_Charge`, which logs 0 samples within it; `25degC/549_C20DisCh_25degC_LGHG2` inside `549_Charge`, which logs 0 samples within it; `25degC/549_Dis_0p5C_25degC_LGHG2` inside `549_Charge`, which logs 0 samples within it; `25degC/549_Dis_2C_25degC_LGHG2` inside `549_Charge`, which logs 0 samples within it).
- *flags*: anything a later stage must handle: name problems, integer storage, NaN rows, Voltage <= 0 rows, backward or stalled Time, pauses that only TimeStamp shows, an overlap with the previous file, a file that opens at rest more than 0.3 V below the end of the previous file (unlogged discharge), a cell temperature more than 5 degC from the folder temperature at the first discharging sample (before self-heating), an Ah counter reset on the last row, or a drive cycle whose integral of I dt is more than 0.01 Ah off its Ah counter.
